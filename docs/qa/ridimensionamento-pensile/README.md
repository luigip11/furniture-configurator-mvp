# Verifica visiva del ridimensionamento del pensile

Prova eseguita il 27 ottobre 2026 sul sito pubblico https://furniture-configurator-ten.vercel.app/configuratore, in Chromium nell’ambiente cloud.

## Sequenza

1. Aprire il catalogo Pensili e aggiungere il pensile orizzontale.
2. Selezionare la variante “Fianco a vista SX / interno DX”, codice `PENSILE_ORIZZONTALE_A_VISTA_SX`.
3. Verificare le misure iniziali: larghezza 700, altezza 439, profondità 350 mm.
4. Inserire larghezza 1400 mm e confermare uscendo dal campo con Tab.
5. Inserire altezza 880 mm e profondità 600 mm, confermando con Tab o Invio.
